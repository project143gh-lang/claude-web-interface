# Claude Web Interface

A web-based interface for interacting with Claude AI. Beautiful, responsive, and easy to use.

## Features

- Clean, modern UI
- Real-time chat interface
- Responsive design
- Easy to deploy

## Quick Start

```bash
# Open in browser
open index.html

# Or serve with any static server
npx serve .
```

## Project Structure

```
claude/
├── index.html          # Main page
├── index.js            # Application logic
└── styles.css          # Styles
```
